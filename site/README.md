# Hevium Landing Page — `site/` Workspace

This directory contains the Next.js 16 (App Router) static export for **[https://hevium.xyz](https://hevium.xyz)**.

See the root **[README.md](../README.md)** for full architecture, contributor guidelines, domain conventions, and Cloudflare deployment details.

## Common Commands

```bash
# Install dependencies (from site/)
pnpm install

# Start local dev server at http://localhost:3000
pnpm dev

# Run Vitest unit tests
pnpm test

# Build static export into site/out/
pnpm run build

# Build and run Playwright E2E test suite
pnpm run e2e
```
